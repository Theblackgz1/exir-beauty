Exir Beauty Clinic landing page
===============================
فایل اصلی: index.html

برای اجرا:
1) پوشه را باز کنید.
2) روی index.html دوبار کلیک کنید، یا با Live Server در VS Code اجرا کنید.

مواردی که باید بعداً با اطلاعات واقعی کلینیک جایگزین شوند:
- شماره تلفن
- آدرس
- لینک واتساپ
- لینک اینستاگرام
- تصاویر واقعی کلینیک و نمونه‌کارها
- متن معرفی پزشکان/متخصصان
